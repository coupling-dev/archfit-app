# Archived design records

These files are the design of the first version of the App. They were moved here on 2026-11-10.

The Archfit 4 design replaces them:
`docs/plans/20261110-archfit-4-architecture-change-control.md` in the [archfit](https://github.com/alexei-led/archfit) repository.
It covers the engine, the Docker image, the GitHub Action, and this App. Its sections 4, 9, and 11.6
restate the constraints that survive.

The code in this repository still implements the first version until the Archfit 4 milestones
change it. For current behavior, read the [architecture](../../architecture.md), the
[user guide](../../user-guide.md), and the `module.md` files. Do not start new work from the
files below.
