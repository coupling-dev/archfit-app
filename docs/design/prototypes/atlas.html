Atlas · design notes

  
Who it suits
Architects who think in diagrams, teams onboarding new engineers, and small or medium repositories.

  
Core bet
If intent and evidence share one picture, people notice erosion without reading reports.

  
What gets easy
  • Seeing where a rule breaks and which modules it involves.
  • Explaining the architecture to a newcomer.
  • Starting a policy change from the thing you look at.

  
What gets hard
  • Readability at 50+ modules. Mitigate with layer bands, grouping by owner, focus mode, filters, and the table twin.
  • Stable layout across reports: positions must not jump.
  • Precise edits such as globs still need text.

  
Data it needs
EXISTS TODAY Policy, latest default-branch report artifact (limited retention), checks, comment, annotations.
NEW PR report artifact for the lens, stored layout, image hosting for the comment image.

  
Build cost
Medium to large. control/ui: layout, interaction, structured edits. gate/feedback only for the optional image.

  
Risks and mitigations
A beautiful hairball. Keep filters, focus, and the table one click away, and default to showing only what needs attention on large repositories.
