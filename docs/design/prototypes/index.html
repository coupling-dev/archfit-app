Design notes

Three pages, three questions

  • Overview: is master fine, and what do I do?
  • Pull request: what is wrong, does it block, how do I fix it?
  • Architecture: where does the code strain the policy?

Rules

  • Status first. One primary action per card
  • Details fold away. Nothing needed to act lives only in a fold
  • The headline says the effect on merge. Never "blocked" when merge is allowed
  • "New" means not in the baseline, not "added by this PR"
  • No score. Evidence is per dimension

States, same words everywhere

No report yet · Report expired · Outdated, re-run · Action required: <reason> · Not found · Rate limited

Prototype controls

Demo switches PR #4 between the real run and projected states. Data sources shows which report field feeds each element.
