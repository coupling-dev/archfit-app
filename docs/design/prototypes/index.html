Design notes

Thesis

Coding agents repair what they break through agent_tasks. Architecture owners only make decisions. The App shows both without inventing either.

Rules this prototype keeps

  • The headline states the effect on merge from gate mode and check conclusion, never from verdict alone
  • "New" means not in the baseline. "Introduced" needs a PR comparison. Never mix them
  • Evidence problems are action required, never neutral, never a verdict on the code
  • Reports are customer-attested, never "verified"
  • No score, no percentage across dimensions
  • Every change is a PR merged on GitHub

Data

Real pilot reports: master at aed8b36 and PR #4 at 9d33f4d. "Projected" scenarios apply #5's baseline to the same findings; they are not real runs.
